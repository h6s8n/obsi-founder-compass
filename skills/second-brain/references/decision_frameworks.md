# Decision & Validation Frameworks (Scientific Toolbox)

Use 2–3 relevant tools from this reference during planning—never apply all at once blindly.

## 1. Multi-Armed Bandit (`80/20 Explore vs. Exploit`) *(Advisory Only — apply strictly in `/obsi-priority` before task/cohort creation, NEVER inside single-project `/obsi-consult`)*
- Never judge noisy channels on `n = 1`. When advisory sequencing across multiple fronts is requested at execution planning time (`/obsi-priority`), suggest `80% Exploit / 20% Explore` options and let the founder choose.

## 2. Sequential Testing & Minimum Sample Size (`No n=1 Decisions`)
- Require an explicit `min_sample_size` before calling `Scale / Pivot / Kill`:
  - YouTube Long-Form: `n = 10–12` consecutive weekly videos.
  - Short-form (Reels/Shorts): `n = 20` videos over 4–6 weeks.
  - X / Reddit / Open-Source demos: `n = 6` distinct hooks/demos over ~6 weeks.
  - Job / Sales Outreach: `quota = 30–50` targeted outreaches.
  - B2B SaaS / Product: `quota = 10` design partners or `100` targeted signups.
- Update beliefs after every iteration (**Bayesian Sequential Updating**) instead of quitting after 1 flop.

## 3. Leading vs. Lagging Indicators
- **Lagging (slow):** Monthly recurring revenue, total subscribers, enterprise contracts.
- **Leading (fast decision signals):** Activation milestone rate, `CTR`, qualified DMs/replies per batch, `Bookmark-to-View`, demo bookings.

## 4. Fast Pre-Build Stress-Tests
- **Smoke Test (Lean Startup):** Validate demand with a 1-day landing/demo/outreach test before a 1-month build.
- **1-Way vs. 2-Way Door (Bezos):** Move fast on reversible 2-way doors; think carefully on irreversible 1-way doors.
- **Pre-Mortem (Gary Klein):** Assume failure 6 months from now -> list top 1–3 causes -> bake countermeasures in now.
- **Opportunity Cost Test:** *(Advisory Only — `/obsi-priority` before task/cohort creation)* Neutrally surface which commitment shares the same weekly slot so the user chooses consciously.
- **10-10-10 Rule:** Check impact in 10 days, 10 months, and 10 years.

## 5. Base Rate Check (Anti-Planning Fallacy)
- Verify published empirical base rates before giving timelines or conversion expectations, distinguishing Leading Indicators from Lagging Outcomes.
